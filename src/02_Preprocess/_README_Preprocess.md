# 前処理系 (02_Preprocess)

このディレクトリは、VOCALOIDのWAV音声とVSQXデータを読み込み、機械学習モデル（DNN）で学習可能なテンソルデータ（`.npz`）に変換するための前処理、および生成されたデータの品質チェックを行うスクリプト群を格納している。

## 各プログラムの説明

* **`preprocess.py`**
  前処理のメインスクリプト。WAVとVSQXのペアデータから音響特徴量とVSQXパラメータを抽出し、正規化を行って学習用の入力データ(X)とターゲットデータ(Y)の `.npz` ファイルを生成する。
  ※Track0（最上段のTrack）のパラメータとwavファイルを結合している。Track0以外のパラメータは使用していない。
* **`config.py`**
  前処理における各種パラメータ（サンプリングレート、パラメータID、正規化の最大値、使用する特徴量の種類など）を一元管理する設定ファイル。`preprocess.py` や各種チェックスクリプトから参照される。
* **`feature_extractor.py`**
  音声信号から音響特徴量を抽出するためのモジュール。`librosa` や `pyworld` などを利用して、メルスペクトログラム、CQT、F0、非周期成分(Aperiodicity)、LPC残差などを計算するクラス (`AudioFeatureExtractor`) を提供する。主に`preprocess.py`で使用する。
* **`check_timelag.py`**
  前処理で抽出された音響エンベロープとVSQXのノート情報を比較し、発声タイミングのズレ（ラグ）を算出するスクリプト。指定フレーム以上ズレているデータ（異常値）を検出し、データセットから除外するために使用される。ずれが発生する原因は調査中。
* **`analyze_vsqx_parameters.py`**
  VSQXファイル内の特定の動的パラメータ（DYNなど）の動きのバラつき（標準偏差）を統計的に分析し、動きの大小に応じて `Active`, `Low_Variance`, `Dead_Flat`（ベタ打ち）に分類・仕分けするスクリプト。

##　処理順序
1.`analyze_vsqx_parameters.py`でパラメータが動いていないデータを削除（データが豊富なら削除しなくてよいが、パラメータが動いていないデータが多いため）
2.wavとvsqxを`config.py`で指定されたディレクトリに配置
3.`config.py`で入力特徴量などを設定
4.`python preprocess.py`を実行
5.`check_timelag.py`を実行してデータのタイムラグをチェック
