# 前処理系 (02_Preprocess)

このディレクトリは、VOCALOIDのWAV音声とVSQXデータを読み込み、機械学習モデル（DNN）で学習可能なテンソルデータ（`.npz`）に変換するための前処理、および生成されたデータの品質チェックを行うスクリプト群を格納している。

## 各プログラムの説明

* **`build_dataset.py`**
  マルチブランチ対応（辞書型構造）となった前処理のメインスクリプト。WAVとVSQXのペアデータを収集し、第1パスで全体の統計量を計算後、第2パスで抽出・正規化を行って学習用の `.npz` とメタデータ `features.json` を生成する。
  入力（X）およびターゲット（Y）データは `config.py` の設定に従ってブランチごとに分割され、`x_branch名` や `y_branch名` のようなキーを持つ辞書形式で `np.savez`として保存される。
* **`config.py`**
  データセット構築における各種パラメータ（サンプリングレート、ディレクトリパスなど）を一元管理する設定ファイル。
  `INPUT_AUDIO_PARAMS`、`INPUT_VSQX_PARAMS`、`TARGET_PARAM_CONFIG` を辞書型で定義することで、後段のニューラルネットワークに合わせて、各特徴量を任意のブランチに割り当てることが可能となっている。
* **`check_timelag.py`**
  前処理で抽出された音響エンベロープとVSQXのノート情報を比較し、発声タイミングのズレ（ラグ）を算出するスクリプト。`build_dataset.py`の動作確認や、指定フレーム以上ズレているデータ（異常値）を検出し、データセットから除外するために使用される。
* **`analyze_vsqx_parameters.py`**
  VSQXファイル内の特定の動的パラメータ（DYNなど）の動きのバラつき（標準偏差）を統計的に分析し、動きの大小に応じて `Active`, `Low_Variance`, `Dead_Flat`（ベタ打ち）に分類・仕分けするスクリプト。

## 処理順序
1. `analyze_vsqx_parameters.py` でパラメータが動いていないデータを削除（データが豊富なら削除しなくてよいが、パラメータが動いていないデータが多いため）
2. WAVとVSQXを `config.py` で指定されたディレクトリに配置
3. `config.py` で入力特徴量や出力対象(ターゲット)などを設定
4. `python build_dataset.py` を実行して `.npz` データセットを構築
5. `check_timelag.py` を実行してデータのタイムラグをチェック
