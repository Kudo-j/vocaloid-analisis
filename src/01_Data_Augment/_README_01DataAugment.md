# データ拡張系 (01_Data_Augment)

このディレクトリは、主にVOCALOIDの学習データの拡張や前処理するためのスクリプト群を格納している。

## 各プログラムの説明

* **`DPara_add_AllTrack.py`**
  VSQXファイルに対して、DYNやPITなどの動的パラメータをルールベースで自動付与・データ拡張するメインスクリプト。フレーズ単位の抑揚（スウェル）やノート単位の揺らぎを、完全に固定された周期ではなく、ノート長に基づいた確率的（Stochastic）なキーフレーム生成を用いて人間らしい自然なカーブとして生成する。
  ※XMLパーサとの相性の問題から、パラメータの書き込みは正規表現を用いたテキスト処理で行っている。
* **`create_untuned_vsqx.py`**
  VSQXファイルから全てのコントロールチェンジタグ（`<cc>`）を正規表現を用いて一括削除し、パラメータが全く付与されていない「ベタ打ち（Untuned）」状態のVSQXファイルを生成するスクリプト。
* **`filter_short_songs.py`**
  VSQXの有効な歌唱区間（有音区間の合計秒数）を解析し、指定した閾値（例: 30秒）に満たないデータ量の少ないファイルを検出して、別フォルダに退避・除外するためのスクリプト。
* **`remove_subtracks.py`**
  VSQXファイル内に複数のトラック（コーラスやハモリなど）が存在する場合に、メインボーカル（Track 0）のトラックのみを残して他のサブトラックをすべて削除するスクリプト。
* **`parameter_trans.py`**
  VSQXファイル内の特定の動的パラメータ（デフォルトはDYN）の値に対して、ランダムな倍率（スケール）とオフセット（シフト）による線形変換を行い、パラメータの振幅バリエーションを生成するスクリプト。
* **`merge_vsparts.py`**
  VSQXファイル内の各トラックに複数存在する`<vsPart>`（歌唱領域ブロック）を時間軸に沿って1つの連続したパートに統合するスクリプト。歌唱領域が複数分かれているとパラメータと音声の時間同期計算に不備が発生しやすいため、データ拡張等の前処理として実行する。
* **`Transpose.py`**
  VSQXデータ内のノートナンバー（音階）を指定した半音分シフト（移調）させることで、異なるキーの学習データを生成するスクリプト。
* **`VocalChange.py`**
  XMLパーサを利用してVSQXファイルを読み込み、指定したボーカルライブラリ（シンガー）に変更して保存するスクリプト。ボーカルを統一させることで学習時の推論品質を安定させる目的で使用する。
* **`classifyVSQX.py`**
  VSQXファイルの先頭を読み込み、バージョン（vsq3 か vsq4 か）を判定してフォルダに仕分けするスクリプト。本プロジェクト群はvsq4形式に対応しているため、vsq3ファイルを検出し、後からPiapro Studioでvsq4に手動変換するために使用する。
* **`randomize_pitch.py`**
  Step 3（音高多様化実験）用に、VSQXデータ内のノート番号を37音階（C3〜C6）の範囲でランダマイズして一括生成するスクリプト。サブトラック自動削除（Track 0のみ保持）機能、同一DYNパターン内での母音間重複を完全回避するラテン方陣配分機能、未学習パターン（Unseen）の割合指定配分機能、音名サフィックス付与機能、代表パターンを用いた音高網羅ベンチマークデータ（全185曲）の一括生成機能、および詳細メタデータログ（Seen/Unseenフラグ付きCSV）の出力機能を備える。
