# データ拡張系 (01_Data_Augment)

このディレクトリは、主にVOCALOIDの学習データの拡張や前処理するためのスクリプト群を格納している。

## 各プログラムの説明

* **`DPara_add_AllTrack.py`**
  VSQXファイルに対して、DYNやPITなどの動的パラメータをルールベース（フレーズ単位の抑揚やノート単位のアタックなど）で自動付与するスクリプト。スウェル（山型・谷型）やドリフト・トレモロといった周期的な揺れの生成パターンが存在する。
  ※パラメータの書き込みの仕方をXML形式ではなく、テキスト形式で行っている。これはXML形式で書き込むと正しくパラメータが付与されないため。vsqx形式とPythonのXMLモジュールの書き込みの相性が悪いため、正規表現で書き込んでいる。
* **`parameter_trans.py`**
  VSQXファイル内の特定の動的パラメータ（デフォルトはDYN）の値に対して、ランダムな倍率（スケール）とオフセット（シフト）による線形変換を行い、パラメータの振幅バリエーションを生成するスクリプト。
* **`merge_vsparts.py`**
  VSQXファイル内の各トラックに複数存在する`<vsPart>`（歌唱領域）を時間軸に沿って結合し、1つの連続したパートに統合するスクリプト。歌唱領域が複数あるとパラメータと歌唱音声の時間同期に不備が発生するため、結合する。データ拡張ではないが、データ拡張前に行うためこちらに配置。
* **`Transpose.py`**
  VSQXデータ内のノートナンバーを指定した半音分シフト（移調）させることで、異なるキーの学習データを生成するスクリプト。
* **`VocalChange.py`**
  XMLパーサ（`minidom`）を利用してVSQXファイルを読み込み、指定したボーカルライブラリ（シンガー）に変更して保存するスクリプト。現在はボーカルを統一させることで学習時の推論品質を安定させる目的で使用している。
* **`classifyVSQX.py`**
  VSQXファイルの先頭を読み込み、バージョン（vsq3 か vsq4 か）を判定して、それぞれのバージョン名のフォルダに仕分けするスクリプト。vsq3とvsq4では形式が違い、ここにあるプログラム群はvsq4対応なので、vsq3ファイルを仕分けする目的で使用している。仕分けたvsq3のファイルは、Piapro Studioを通してvsq4形式に変換を行う。
