# 【旧システム】DNN学習・推論系 (03_DNN_System)

> [!WARNING]
> **本ディレクトリは過去に作成された旧システムである（現在は不使用）。**
> 初期のTransformer（エンコーダ・デコーダ）モデルの検証用スクリプト群であり、現行のDNNモデリング・学習・推論・評価パイプラインはすべて `src/05_Step_Experiments` に移行している。

このディレクトリは、初期に開発されたTransformerベースのモデル定義および学習・推論・評価スクリプト群を格納している。

## 共通プログラム・推論・評価

* **`dataset.py`**
  旧DNN学習用のデータセット（DataLoader）を管理・生成する。`02_Preprocess` で作成された特徴量ファイル群を読み込み、指定されたチャンクサイズ（時間フレーム単位）に分割してモデルへ入力可能なテンソル形式（バッチ）に変換する役割を持つ。
* **`predict_dec.py` / `predict_en.py`**
  学習済みの旧モデル（`.pth`）を読み込み、未知の楽曲データ（WAVとVSQX）から動的パラメータを予測出力する推論用スクリプト。`predict_dec.py` はデコーダありモデル、`predict_en.py` はエンコーダ単体モデルに対応する。
* **`eval_Test_deco.py` / `eval_Test_enco.py`**
  テスト用データセットに対して学習済みモデルを一括適用し、楽曲ごとの推論精度（MSE Loss や Diff Loss）を算出して Excel (`.xlsx`) レポートとして出力する評価用スクリプト。

## 学習・モデルプログラム

アプローチの違い（デコーダの有無）により、2組のモデルと学習スクリプトのペアが存在する。

### 1. デコーダありモデル
* **`model_decoder.py`**
  エンコーダとデコーダの両方を持つTransformerモデル。
* **`train_decoder.py`**
  `model_decoder.py` を用いて学習を行うスクリプト。

### 2. エンコーダ単体モデル (デコーダなし)
* **`model_encoder.py`**
  デコーダを持たないエンコーダ単体のTransformerモデル。
* **`train_encoder.py`**
  `model_encoder.py` を用いてエンコーダのみでの学習を行うスクリプト。
