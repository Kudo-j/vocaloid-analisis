# DNN学習・推論系 (03_DNN_System)

このディレクトリは、前処理で生成されたテンソルデータ(`.npz`)を用いて、VOCALOIDの動的パラメータを推論するためのDNNモデルの学習、および学習済みモデルを用いた未知データに対するパラメータ予測（推論）を行うスクリプト群を格納している。

## 共通プログラム・推論・評価

* **`dataset.py`**
  DNN学習用のデータセット（DataLoader）を管理・生成する。`02_Preprocess` で作成された特徴量ファイル群を読み込み、指定されたチャンクサイズ（時間フレーム単位）に分割してモデルへ入力可能なテンソル形式（バッチ）に変換する役割を持つ。
* **`predict_dec.py` / `predict_en.py`**
  学習済みのモデル（`.pth`）を読み込み、未知の楽曲データ（WAVとVSQX）から動的パラメータを予測出力する推論用スクリプト。`predict_dec.py`はデコーダありモデル、`predict_en.py`はエンコーダ単体モデルに対応する。
  `02_Preprocess` の `config.py` と連携し、自己回帰的またはチャンクベースで処理を行い、推論結果と正解パラメータを比較したグラフと、vsqxファイルを生成する。
  > [!IMPORTANT]
  > **WAVファイルの時間同期（AUDIO_START_TICK）について**
  > 推論対象となるWAVファイルをDAWから書き出した際、「VSQX上のどこから書き出したか（曲の先頭か、特定のパートの開始位置か）」によって時間同期がズレる問題が発生する。
  > 本スクリプト群では内部の `AUDIO_START_TICK` 変数を用いてこのオフセットを吸収する設計となっており、実行前に適切な書き出し開始Tick（例: `Test1.wav` はvsPartの開始位置である `9600`、通常のプレメジャー終了位置なら `7680` 等）を設定する必要がある。
* **`eval_check.py`**
  テスト用データセットに対して学習済みモデルを一括適用し、楽曲ごとの推論精度（MSE Loss や Diff Loss）を算出して Excel (`.xlsx`) レポートとして出力する評価用スクリプト。推論用スクリプトと異なり、vsqxファイルを生成しない。

## 学習・モデルプログラム

現在、アプローチの違い（デコーダの有無）により、2組のモデルと学習スクリプトのペアが存在している。

### 1. デコーダありモデル
* **`model.py`**
  エンコーダとデコーダの両方を持つ標準的な Transformer モデル。
* **`train_decoder.py`**
  `model.py` を用いて学習を行うスクリプト。通常のMSE Lossに加えて、パラメータの変動量（微分値）を考慮した Derivative Loss（`AdvancedLoss`）を組み込み、学習を実行する。

### 2. エンコーダ単体モデル (デコーダなし)
* **`model_encoder.py`**
  デコーダを持たないエンコーダ単体の Transformer モデル。`model.py` と基本設計（埋め込み層・出力の移動平均・Tanh等）を完全に同一にしており、純粋にデコーダの有無による性能差を比較できるように設計されている。
* **`train_encoder.py`**
  `model_encoder.py` を用いてエンコーダのみでの学習を行うスクリプト。
