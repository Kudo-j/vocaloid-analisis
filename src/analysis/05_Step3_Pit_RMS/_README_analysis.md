# 音響・物理特性解析系 (analysis/05_Step3_Pit_RMS)

本ディレクトリは、歌声の音高（ピッチ）と音響エネルギー（RMS）の相関、および母音フォルマントと倍音共鳴の物理的特性を解明・実験するためのスクリプト群を集約した作業領域である。

## 各プログラムの説明

* **`analyze_formant_harmonics.py`**
  音高とRMSの相関機序（なぜ特定の音高と母音の組み合わせでエネルギーが増減するのか）を解明するため、LPC分析による母音フォルマント包絡線と音高の倍音成分を重ね合わせて可視化・分析するスクリプト。
  1. C3〜B4の歌唱から生成した各母音のスペクトル包絡
  2. C音系列（C3, C4, C5）の倍音と5母音包絡線の重ね合わせ
  3. 母音「あ」におけるD#4とF#4の倍音共鳴配置比較（D#4で共鳴が大きく、F#4で小さい物理的要因の可視化）
  などの分析グラフを自動生成する。
* **`analyze_pitch_rms.py`**
  C3〜C6（全37段階の音階）の歌唱音声からRMSを抽出し、音高とRMSの関係を母音別に詳細分析するスクリプト。連続音高プロット、オクターブ重ね合わせプロット、および全音高×全母音の統計量を含むExcelレポート（`pitch_rms_analysis_report.xlsx`）を出力する。
* **`randomize_pitch.py`**
  Step 3（音高多様化実験）用に、VSQXデータ内のノート番号を37音階の範囲でランダマイズして一括生成するデータセット生成スクリプト。同一DYNパターン内での母音間重複回避、未知の（音高×音素）組み合わせを配分したOpen評価用データ分割、および音高網羅ベンチマークデータ（全185曲）の自動生成とログCSV出力を行う。
* **`evaluate_pitch_benchmark.py`**
  Step 3専用の音高網羅ベンチマーク評価スクリプト。学習済みDNNモデルを用いて全37音階×5母音（185曲）の推論を一括実行し、正解vs予測の比較波形プロットを保存するとともに、Seen（既知）vs Unseen（未知）や音高別・母音別の誤差統計（MSE、MAE、相関係数等）を集計したExcelレポートを出力する。
