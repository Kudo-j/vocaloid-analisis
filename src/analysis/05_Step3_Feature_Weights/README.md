# Step 3 音響特徴量 重み解析ツール (05_Step3_Feature_Weights)

## 概要

本ツールは、Step 3（音高多様化実験）で学習された各音響特徴量（5種：メルスペクトログラム、バークスペクトログラム、MFCC、定Q変換CQT、RMSエネルギー）およびデータ倍率（1〜5倍）のモデル（`best_model.pth`）から、入力全結合層（`fusion.branches.audio.0.weight`）の重みを抽出し、次元・周波数別の重要度を可視化・データ化するための解析モジュールである。

各次元の重みノルム（L2ノルム / L1ノルム）の計算、物理周波数（Hz）へのマッピング、Excelファイル（`.xlsx`）への出力、および折れ線グラフとヒートマップの自動生成を一括で実行する。

## 出力ファイル仕様

### 1. Excelファイル (`output/xlsx/*.xlsx`)
各特徴量ファイル内に以下のシートを収録する。
- **重み一覧_L2ノルム**: 各次元インデックス、中心周波数（Hz）、および1〜5倍データの重みL2ノルム、平均値、標準偏差。Excel上でソートやフィルタリング、自作グラフ作成が可能。
- **重み一覧_L1ノルム**: 各次元の重みL1ノルム（絶対値総和）。
- **メタ情報**: 特徴量名、次元数、サンプリングレート、ブランチ除算係数（`calibrated_scales`）。

### 2. 可視化画像 (`output/figures/*.png`)
- **`*_折れ線.png`**:
  下側X軸に実周波数（Hz）、上側X軸にビン次元インデックスを配置した2軸折れ線グラフ。1倍から5倍データの5本の線をグラデーション表示し、データ増加に伴うピークの尖鋭化や学習深化を定量的に比較可能。
- **`*_ヒートマップ.png`**:
  縦軸にデータ倍率（1〜5倍）、横軸に周波数・次元を配置したヒートマップ。全体の重み分布の広がりを一目で俯瞰可能。
- **`RMSエネルギー_推移.png`**:
  1次元の物理エネルギー特徴量について、倍率に伴う重み推移を示す棒グラフ。

## 実行方法

スクリプト内の `CONFIG` 領域にパスやパラメータが集約されているため、設定変更なしで実行可能である。

```bash
python src/analysis/05_Step3_Feature_Weights/extract_and_plot_weights.py
```
