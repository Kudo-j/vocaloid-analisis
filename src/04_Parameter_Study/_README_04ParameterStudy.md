# パラメータ調査・音響分析系 (04_Parameter_Study)

このディレクトリは、歌声の音響的特徴量（WAV）と、VOCALOIDの動的パラメータ（VSQX）間の相関関係や影響度を調査・可視化するための分析スクリプト群を格納している。

## メイン分析スクリプト

* **`compare.py`**
  パラメータを書き込んだ音声と書き込んでいない音声を比較し、VSQXパラメータの変動と音響特徴量の相関関係や影響度を可視化・分析するメインスクリプト。
  ｛あ（パラメータ有）ー あ（無）｝の形で比較を行う。
* **`compare_config.py`**
  `compare.py` および `analyze_single.py` を実行するための共通設定ファイル。入力ディレクトリパス、比較対象パラメータ、抽出する音響特徴量の設定などを一元管理する。
* **`analyze_single.py`**
  単一の音声（WAV）とVSQXデータから設定された音響特徴量を抽出し、時間変化を1枚の画像にプロットするツール。比較や差分計算を行わず、純粋な特徴量の変動を観察したい場合に使用する。
* **`compare_vowels.py`**
  「あ」と「い」などの母音ごとに、VSQXパラメータの効き具合（音響特徴量への感度）がどのように変化するかを特化して分析・比較するスクリプト。
  ｛あ（パラメータ有）ー あ（無）｝ー｛い（パラメータ有）ー い（無）｝という形で、差分の差異を比較する。
* **`vowel_compare_config.py`**
  `compare_vowels.py` を実行するための専用設定ファイル。
* **`note_boundary_study.py`**
  ノートの開始点・終了点（発声境界）におけるRMS等の音響エネルギーの挙動を追跡し、ノート境界でどのような推移が発生しているかを調査するスクリプト。

## 特化型・比較ビューア

* **`view_spectral_envelope.py`**
  DYNなどが一定値で持続する複数のWAVファイルのスペクトル包絡を重ねてプロットし、フォルマント構造の変化を直接観察するビューア。
  `ANALYSIS_METHOD` を切り替えることで、精密な `CheapTrick` による包絡か、滑らかで数学的にフォルマントと一致する `LPC` (Librosaベース) による包絡抽出かを選択可能である。
* **`view_multi_features.py`**
  複数のWAVファイルから抽出した特定の1次元音響特徴量（RMS, F0, フォルマント振幅など）を同一グラフ上に重ねてプロットするツール。母音間や異なるDYN値間での時間的変化の違いを直接比較できる。

## ユーティリティスクリプト

* **`generate_vsqx_vowels.py`**
  歌詞変換スクリプト。
  ベースとなる「あ」のVSQXファイルを元に、DYNなどのコントロールカーブを維持したまま、ノート内の歌詞と音素情報だけを安全に置換し、「い・う・え・お」のVSQXファイルを一括生成する。

## コアモジュール (`src/` フォルダ内)

* **`audio_analyzer.py`**
  抽出された特徴量をVSQXパラメータと紐づけ、相関係数や効果量などの統計的処理や描画設定を統合管理する中核クラス。
  ※なお、音響特徴量の汎用抽出エンジンは共通基盤である `src/util/feature_extractor.py` を利用する。
* **`diff_visualizer.py`**
  基準となるデータ（デフォルトパラメータ）と、編集後のデータの差分（Diff）を可視化・プロットする描画モジュール。
* **`vowel_visualizer.py`** / **`vowel_diff_visualizer.py`**
  母音別の音響特徴量の分布や、母音ごとのパラメータ感度の差分を特化してグラフ化する描画モジュール群。
