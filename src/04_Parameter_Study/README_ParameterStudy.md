# パラメータ調査・音響分析系 (04_Parameter_Study)

このディレクトリは、歌声の音響的特徴量（WAV）と、VOCALOIDの動的パラメータ（VSQX）間の相関関係や影響度を調査・可視化するための分析スクリプト群を格納している。

## メイン分析スクリプト

* **`compare.py`**
  パラメータを書き込んだ音声と書き込んでいない音声の比較を行い、VSQXパラメータと音響特徴量の関係を比較分析するメインスクリプト。内部で `compare_config.py` の設定を読み込み、`src` ディレクトリ配下のモジュール群を呼び出して相関関係の計算や可視化を実行する。
* **`compare_config.py`**
  `compare.py` を実行するための入力ディレクトリパス、比較対象パラメータ、相関を算出するかどうかのフラグなどを一元管理する設定ファイル。
* **`compare_vowels.py`**
  「あ」と「い」などの母音ごとに、VSQXパラメータの効き具合（音響特徴量への感度）がどのように変化するかを特化して分析・比較するスクリプト。
  ｛あ（パラメータ有）ーあ（パラメータ無）｝ー｛い（パラメータ有）ーい（パラメータ無）｝...という形で比較を行っている。
* **`vowel_compare_config.py`**
  `compare_vowels.py` のための各種設定ファイル。母音ごとの分析に特化したパラメータ設定を持つ。


## コアモジュール (`src/` フォルダ内)

* **`feature_extractor.py`**
  WAVファイルからF0, RMS, LPC, Aperiodicity（非周期成分）などの音響特徴量を抽出するモジュール。
* **`audio_analyzer.py`**
  抽出された特徴量をさらに分析し、VSQXパラメータとの相関係数や効果量などを統計的に計算する処理を担当する。
* **`vsqx_reader.py`**
  `02_Preprocess` の `preprocess.py` の解析ロジックをベースに、比較表示に必要な情報のみを軽量に抽出する簡略版のVSQXリーダー。

## 可視化モジュール (`src/` フォルダ内)

* **`diff_visualizer.py`**
  基準となるデータ（デフォルトパラメータ）と、編集後のデータの差分（Diff）を可視化・プロットするツール。
* **`vowel_visualizer.py`**
  母音別の音響特徴量やパラメータの分布をグラフ化（ヒートマップ、棒グラフなど）する。
* **`vowel_diff_visualizer.py`**
  母音ごとに差分がどのように表れるかを特化して可視化するモジュール。
